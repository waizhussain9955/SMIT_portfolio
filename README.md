# SMIT_portfolio

Personal Developer Portfolio of **Waiz Hussain** — Full Stack Developer & AI Builder.

## 🚀 Overview
Modern, accessible, responsive portfolio built with:
- **Framework:** Next.js (App Router)
- **Language:** TypeScript (Strict)
- **Styling:** Tailwind CSS & Obsidian Dark Theme tokens
- **Icons:** Lucide React
- **Architecture:** Spec-Driven Development (SDD), typed centralized content (`src/data/portfolio.ts`)

## 🛠️ Features
- **Dark & Light Modes:** Obsidian luxury theme with smooth toggle.
- **Interactive Project Showcase:** 12 verified projects with categorization filters and detailed modal views.
- **Technical Skills Matrix:** Categorized core skills, frontend, backend, AI systems, and tools.
- **Direct Contact:** 1-click email copy with clipboard feedback, direct WhatsApp link, and mailto form validation.
- **Fully Responsive & Accessible:** Tested across viewports with keyboard navigation and WCAG 2.1 AA principles.

## 💻 Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
